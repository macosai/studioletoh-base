# Contributing

This repository is source-available, not open-source. The license allows personal use, not resale or redistribution. Read [LICENSE.md](LICENSE.md) before you send anything.

## Bugs and docs

Bug reports and documentation fixes are welcome through [GitHub Issues](https://github.com/macosai/studioletoh-base/issues).

Please include:

- the Lua version
- the module and function
- the smallest input that shows the problem
- what you expected and what happened

## Pull requests

Pull requests are not accepted by default. If you want to propose a change, open an issue first and describe the problem. Do not send product code, reverse-engineered code, or code you do not have permission to share.

If we agree on a change, you must be allowed to submit the code, and Studio LETOH must be allowed to use it under the same license.

## Product support

This repo covers the base library only. For help with a paid product, use the contact page on the [Studio LETOH store](https://store.letoh.jp).

## Security

Do not open a public issue for a security problem. Contact us through the store so we can look at it privately.
